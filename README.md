# ⚔️ AETHERIA: Echoes of the Fallen

[![iOS unsigned IPA](https://github.com/yhjdjd20-del/ggbb/actions/workflows/ios-unsigned-ipa.yml/badge.svg)](https://github.com/yhjdjd20-del/ggbb/actions/workflows/ios-unsigned-ipa.yml)

**Сложная action-RPG-платформер для iOS** — Swift, SpriteKit + SwiftUI.

> 🤖 Каждый пуш автоматически собирается в **неподписанный .ipa** (GitHub Actions → Artifacts). Теги вида `v1.0.0` публикуют IPA в Releases.

Тёмная сказочная история: Разлом пожирает небо, и только герой, пахнущий рассветом, может закрыть его — пройдя 4 региона, победив 3 стражей и собрав силу Эха.

## 🎮 Что внутри

**Мир и геймплей**
- 4 региона: Шепчущий лес 🍃, Пещеры Эха 🕯️, Тихая крепость 🌧️, Небесные руины ❄️
- Платформинг: coyote time, jump buffer, двойной прыжок, рывок с неуязвимостью, лестницы, движущиеся платформы, односторонние платформы
- День/ночь, погода (дождь, снег, пепел, листва) — влияет на игру: реген маны, скорость врагов, опыт, золото
- Параллакс-фоны, 70+ процедурных спрайтов (весь арт рисуется кодом — ни одного PNG, кроме иконки)

**Бой**
- Комбо из 3 ударов, криты, нокбэки, фреймы неуязвимости
- Магические болты, огненные бомбы, добивание снарядов мечом
- 6 типов врагов с ИИ (прыгуны, летуны, лучники, штурмовики, призраки, телепортирующиеся маги)
- 3 босса с фазами и телеграфами атак: голем, рыцарь, дракон
- Всплывающий урон, тряска камеры, счётчик комбо

**RPG-системы**
- 3 класса: Рыцарь / Следопыт / Маг (уникальные старты)
- Опыт, уровни, очки атрибутов (СИЛ/ЛВК/ВЫН/ИНТ)
- Дерево из 18 навыков в 3 ветках с требованиями и тирами
- 37 предметов: оружие, броня, амулеты, зелья, материалы, ключевые
- 12 квестов (сюжет + побочные), трекер, журнал
- Диалоги с выборами, условиями и наградами; 4 торговца
- 14 достижений, 3 слота сохранений, автосейв, чекпоинты
- Процедурный звук: все эффекты и 6 музыкальных тем синтезируются кодом (AVAudioEngine)
- Управление: тач (джойстик + кнопки), клавиатура, MFi-геймпады, хаптика
- Локализация RU/EN, 3 сложности, миникарта в реальном времени

## 🛠 Сборка

Требуется **Mac с Xcode 16+**.

```bash
git clone https://github.com/yhjdjd20-del/ggbb.git
cd ggbb
git checkout arena/01a0ab85-ggbb
open Aetheria.xcodeproj
```

В Xcode: выбери симулятор iPhone (например, iPhone 16) → **⌘R**.
Для запуска на устройстве: в Signing & Capabilities выбери свою команду разработки.

> Проектный файл `Aetheria.xcodeproj` генерируется скриптом `tools/generate_project.py` из файлов на диске. Добавил новый `.swift`/`.json`? Перезапусти скрипт:
> ```bash
> python3 tools/generate_project.py
> ```

## 🗺 Структура

```
Aetheria/
├── App/            # Точка входа, GameViewModel (мост SwiftUI↔SpriteKit), ввод, настройки
├── Models/         # Модели данных, loader JSON, RU/EN-строки
├── Systems/        # Бой, сохранения, процедурный звук/арт, достижения, геймпад
├── Game/           # Игрок, враги, боссы, сцена, HUD, погода, построитель уровней
├── Views/          # 19 SwiftUI-экранов: меню, инвентарь, навыки, квесты, диалоги…
├── Resources/Data/ # Контент в JSON: предметы, навыки, враги, квесты, диалоги, уровни
└── Assets.xcassets # Иконка и цвета
```
